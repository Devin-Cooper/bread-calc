# Privacy

`breadmachine.io` is fully static and self-hosted from GitHub Pages. There are:

- No analytics, no telemetry, no third-party scripts, no third-party fonts.
- No cookies. No localStorage tracking. (LocalStorage is used only for recipe autosave and is never transmitted.)
- URL-hash sharing (`?r=…` actually `#r=…`) is opt-in and explicit; the recipe payload never leaves your browser unless you copy and share the URL yourself.

The CLI and library make zero network calls.
